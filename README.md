# FeteDuJour
Fetedujour.fr vous permet d'afficher la fête du jour.

Le plugin Fête du Jour permet à A.V.A.T.A.R de connaître et d'annoncer automatiquement la fête du jour.

Il utilise les données de Fetedujour.fr pour récupérer le prénom ou les prénoms célébrés chaque jour.

Exemples de commandes :

« Quelle est la fête aujourd'hui ? »
« Qui fête-t-on aujourd'hui ? »
« C'est la fête de qui ? »
« Quele est le prénom du jour ? »


- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

## Multi-room

The FeteDuJour plugin is fully multi-room.

## Multi-language

The FeteDuJour plugin relies solely on the system's available languages.
